# Focused validation session 01

## Purpose
Find a small portfolio of well-validated problem statements before generating any hackathon solution. Do not invent ideas and do not treat popularity as validation.

## Reddit state
Reddit is paused. Self-serve app creation/access is blocked or restricted by current Responsible Builder Policy requirements. Do not retry credentials, use Devvit as a workaround, or bypass access controls. Use HN, GitHub Issues, and Lobsters only unless an approved dataset is explicitly sourced.

## Collection boundary
The previous broad 120-hit pass is closed. This session uses targeted queries only. Every result must retain its original URL, source publication time, collection time, and lineage key. Reposts and quoted material count as one lineage.

## Validation gate for each candidate
A candidate may be called validated only when it has:
1. Three or more independent first-person or incident reports sharing the same user/task/failure/consequence.
2. A concrete current workaround and evidence that it fails or costs enough.
3. At least two existing conventional tools tested or checked, with the residual gap written precisely.
4. A reproducible fixture or measurable benchmark.
5. A clear reason the problem matters to a defined operator group.
6. No forced NVIDIA/Nebius mapping; feasibility is checked only after the gap survives.

## Directed tracks
- API/dependency drift: three ecosystems, one same failure class.
- Evidence/research reconciliation: one narrow reconciliation failure, not paper search.
- Operational false positives: one detector and one reproducible false-positive class.
- Long-video review: one operator group, one event, one measurable miss.

## Deliverables
- `evidence/cards/` with verbatim quotes and provenance.
- `evidence/portfolio.md` with status: candidate/investigating/validated/rejected/unresolved.
- `evidence/validation-session-01.md` with source matrix, alternatives, and kill decisions.
- No prototype or idea generation until at least one candidate passes the gate.
