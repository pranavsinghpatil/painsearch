# Targeted discovery pass — 2026-09-17 10:56

Sources used: HN Algolia, GitHub Issues API, and Lobsters feeds (`hottest`, `newest`, `active`). Reddit was not used. Six domain queries produced 170 raw records; most were product launches or feature proposals and were not counted as independent pain evidence.

## Result 1 — third-party integration drift

Existing registry record: **P0004**.

Evidence:
- [Ask HN: third-party API changes](https://news.ycombinator.com/item?id=47538731): one team reports 10+ APIs, two silent breaking changes in a year, and discovery only after users complained.
- [ts-node ESM issue](https://github.com/TypeStrong/ts-node/issues/1007): downstream breakage from Node loader API changes.
- [Office.js community issue](https://github.com/OfficeDev/office-js/issues/6513): large aggregate of platform regressions and unstable remote behavior.

Status: **investigating, strongest current lead**.

Required test: reproduce one silent contract change and compare pinning, contract tests, synthetic checks, and changelog monitoring. A model is not justified unless those baselines leave a measurable residual gap.

## Result 2 — cross-system data correctness

Evidence:
- [Datafold](https://news.ycombinator.com/item?id=24071955): a data engineer reports a SQL change corrupting downstream data; custom comparison can take 100+ lines of SQL and hours.
- [Prequel Google Sheets sync](https://news.ycombinator.com/item?id=34548663): existing product describes reconciliation/upsert and data-size problems when syncing warehouse data into Sheets.
- [Argo CD sync status discrepancy](https://github.com/argoproj/argo-cd/issues/7629): a separate issue reports disagreement between current and last sync status.

Status: **real pain, likely mature solution space**. Do not promote until one narrow failure remains after Datafold/dbt/Argo-style baselines.

## Result 3 — false-positive security and operational alerts

Evidence:
- [Create React App npm audit issue](https://github.com/react/create-react-app/issues/11174): maintainers describe large volumes of irrelevant transitive-dependency warnings obscuring real vulnerabilities.
- [DependencyTrack false-positive CVE](https://github.com/DependencyTrack/dependency-track/issues/5165): an advisory is reported for an environment where its platform does not apply.
- [Uptime Kuma false-down issue](https://github.com/louislam/uptime-kuma/issues/774): one connectivity failure creates many incorrect service-down alerts and bad uptime data.

Status: **multiple pains, not one micro-problem**. Reject the broad "AI alert triage" framing. Reopen only around one detector and one reproducible false-positive class.

Evidence:
